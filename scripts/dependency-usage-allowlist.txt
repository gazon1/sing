# This list exists so the gate can be ON while the debt is worked off, which is
# the point: #205 measured that the naive prefix heuristic reports 45 unused

# gate, and an allowlist of *verified* findings is not the same as one of guesses
# — every entry below was hand-checked against the source tree.
#
# The count may go DOWN and never UP. Adding a line is a claim that a new
# unused dependency is acceptable, which needs a reason in the commit, not a
# number.

# lost is worth recording: `ai.koog:prompt-executor-openai-client` *is* used, by
# a fully-qualified name in two DI modules. The gate could not see a reference
# with no import statement, so it reported a live dependency as dead — which is
# the failure mode #205 warned about, arriving from the other direction.
