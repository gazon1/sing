# PR-1.2 Retro — docs-infrastructure FILES

## Context

Created `docs/CONTEXT.md` (12 domain terms), `PROGRESS.md` (template), and two skills (`domain-glossary`, `progress-journal`). Applied ADR frontmatter normalization to 8 older ADRs.

## Findings

### ✅ What was done
- 12 domain terms documented in CONTEXT.md
- PROGRESS.md provides shared progress tracking for the epic
- `domain-glossary` skill: decision tree for term inclusion
- `progress-journal` skill: how to update PROGRESS.md during an epic
- All 78 skills pass `check-skill-frontmatter` validation

### 🟡 What didn't go well
- **DIGEST still oversized** (1683 lines, limit 1500) — same as before PR-1.2. Adding 4 more ADRs and content in PR-1.2 did not increase DIGEST line count (normalized ADRs only added `status: accepted`). The root cause is cumulative: too many ADRs each with multiple Critical bullets.
- **ADR frontmatter normalization** — `just docs-audit` revealed 8 older ADRs missing `status: accepted`. This is a pre-existing hygiene debt. Normalized as part of this PR but it should have been caught earlier.
- **just docs-audit reveals issues** — the frontmatter normalization and DIGEST refresh both run as part of the audit. Both found actionable issues. Good tool, but output is noisy.

### 🔴 Critical fixes (none needed)

### 🟡 ADR-worthy

1. **DIGEST oversized** — 1683/1500 lines. Options:
   - **Trim bullets**: reduce verbosity in Critical section (hard, every bullet is essential)
   - **Split DIGEST**: one per category (critical/warnings/deprecated/deferred) 
   - **Increase limit**: bump to 2000 or 2500 (easy but avoids root cause)
   - **Archive old ADRs**: move very old accepted+applied ADRs to `docs/decisions/archive/`
   - **Recommended**: archive old ADRs that are fully applied and no longer referenced in code. Target: reduce to ~1400 lines.

2. **ADR frontmatter normalization should be CI** — the `normalize-adr-frontmatter.sh --apply` should run in CI, not as a manual step. Currently `just docs-audit` only does dry-run. Recommend: add `--apply` to CI gate.

## Consequences (new rules for DIGEST)

- No new critical/warnings bullets from this PR (process/content ADRs)
- `just docs-audit` in CI should run `normalize-adr-frontmatter.sh --apply` (not dry-run)
