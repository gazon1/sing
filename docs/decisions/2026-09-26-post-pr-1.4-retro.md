# PR-1.4 Retro — Skills Reorg

## Context

Skills reorg: koin-di DEPRECATED, vm-migration-playbook trimmed (15.5KB→11.9KB), feature-scaffold trimmed (38KB→17KB) + TOC added, vm-pattern-overview updated.

## Findings

### ✅ What was done
- koin-di now correctly marked deprecated with alternative = koin-dsl
- All 3 oversized skills brought within limits (feature-scaffold 17KB, vm-migration 11.9KB, koin-di stub 7KB)
- feature-scaffold TOC added (16 entries)
- vm-pattern-overview table updated to reference koin-dsl

### 🟡 What didn't go well
- **feature-scaffold was 38KB** — the largest skill by far, nearly 2x the hard cap. Required significant trimming. Root cause: accumulated verbose examples over multiple revisions. Lesson: size limits should be enforced in CI (currently only `check-skill-frontmatter.sh` validates frontmatter, not size).
- **koin-di was never deprecated in P0** — the retro from PR-0.3 flagged "koin-di skill should be DEPRECATED" but it wasn't done until PR-1.4. Should have been a fast-follow.

### 🔴 Critical fixes (none needed)

### 🟡 ADR-worthy

1. **Skill size limits not enforced in CI** — `check-skill-frontmatter.sh` validates frontmatter but not size. Add `wc -c` size check to CI. Limit: 20KB hard cap.

2. **DIGEST still oversized** (1702/1500 lines) — same as PR-1.3. Need to address this before final retro. Options: archive old applied ADRs, split DIGEST by category, increase limit.

## Consequences

- No new critical/warnings bullets from this PR
- Skill size check should be added to CI
