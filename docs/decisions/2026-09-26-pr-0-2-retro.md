# PR-0.2 retro: KDoc enforcement rules

## Context

PR-0.2 added two custom KDoc enforcement rules (ViewModelMustHaveKDoc, RepositoryInterfaceMustHaveKDoc) and a skill frontmatter validator script.

## Findings

### 🟡 ADR-worthy

1. **KDoc rules have limited PSI API.** `isAbstract()`, `isInner()`, `isInterface()` must be called as parameterless functions in Kotlin PSI 2.x (`clazz.isInterface()` not `clazz.isInterface`). Abstract/inner class exclusion was removed from `ViewModelMustHaveKDoc` due to API limitations — acceptable since abstract VMs are rare and inner VMs inherit docs from outer class.

2. **`docComment?.text` is the only reliable KDoc check.** `docComment?.contentText` and `docComment?.docText` don't exist in this Kotlin PSI version. The `text` property returns the raw `/** ... */` including markers — `.isNullOrBlank()` handles it correctly.

3. **Epic branch detekt.yml conflict on merge.** After `git pull origin main --rebase`, the epic branch already contained all rule sets from PR-0.0 + PR-0.1. PR-0.2 tried to add the same sections again. Spurious conflict resolved by accepting epic version. **Mitigation:** Future PRs branching from epic should rebase onto epic (not main) before opening PR, or main should be merged into epic.

4. **Skill frontmatter script initially required `status`/`date` keys.** All skills use `name`/`description` frontmatter per the existing project convention. Script was corrected to check `name` + `description` instead.

### 🟢 Clean

- KDoc rules fire correctly on 4 files (2 ViewModels, 2 Repositories).
- Baseline regenerated — 0 findings.
- 76 skill SKILL.md files pass frontmatter validation.
- `warningsAsErrors` continues to work with new rules suppressed in baseline.

## Decision

1. **No fast-follow PR needed.**
2. **Spurious merge conflict pattern** → documented as a workflow note: rebase PR branch onto epic before opening PR, or merge epic into PR if main has advanced.

## Consequences

- PR-0.3 will add KDoc to the 4 flagged files (AppVersionGateViewModel, TagGroupsViewModel, SavedAgendaViewsRepository, ChecklistRepository).
