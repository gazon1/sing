# Maestro flows that may name a point in pixels.
#
# The rule (`scripts/check-maestro-screen-geometry.py`): a flow must not
# address a point in pixels. A point is a claim about the display it was
# measured on — a point at y=2000 is off-screen on a 720×1600 phone, the
# gesture never happens, and the flow fails on a screen it never claimed to
# know about.
#
# This file is the exceptions registry. A flow listed here may name a pixel,
# and it must say why: the second column is the reason, and a blank reason is
# a finding, because "no reason" is not a reason.
#
# Format: one `<path-relative-to-Maestro> <reason>` per line. `#` starts a
# comment. The path is relative to `Maestro/`, so a helper is
# `helpers/settings-account-tab.yaml`.
#
# The gate also fails when a listed flow no longer names a pixel: a stale
# exception is a claim that is no longer true, and it hides the day the flow
# is fixed.
#
# ── The date picker sheet ─────────────────────────────────────────────────
#
# The date picker's action row sits at the bottom of the sheet's scrolling
# column, and the sheet is a `ModalBottomSheet` whose content is a plain
# `Column` with the scroll on the `SheetScaffold` — a point inside the sheet
# is the only way to reach the row (measured 2026-10-28: a swipe on the
# sheet's own element scrolls the calendar, not the column that holds OK).
