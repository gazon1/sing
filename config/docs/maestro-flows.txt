# The Maestro flows this repository expects to have, one per line, as the path
# relative to the repository root.
#
# This list is a promise, not a description. `scripts/check-maestro-flow-catalogue.py`
# holds the tree to it in both directions: a flow that is not listed here is a
# finding, and a line here that no longer has a file is a finding too. Both mean
# the suite is not the suite we said it was, and a suite that changes shape
# silently makes every green run before it incomparable to every green run after.
#
# The directory decides the suite, not this file: everything under `smoke/` runs
# on every push, everything under `Maestro/flows/` runs in the nightly full
# suite. The catalogue does not assign suites — it only says which flows exist.
#
# To add a flow: add the file, add the line here, in the same commit.
# To remove a flow: remove the file, remove the line here, in the same commit,
# and say why in the commit message. A flow can also be removed without being
# deleted — a flow that asserts an element the app cannot render is worse than
# no flow, because it fails for a reason nobody is looking for.
#
