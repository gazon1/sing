# The Maestro elements that are waited for, and the kind each one belongs to:
# `<maestro id> <kind>` per line, sorted by id.
#
# This file is the promise that every element a flow waits for has a budget:
# `scripts/check-ui-wait-budgets.py` holds every wait to the budget of the kind
# its element belongs to, and an element that is not listed here is a finding —
# an element nobody budgeted is a budget nobody keeps in step.
#
# The kinds are the ones `config/docs/ui-wait-budgets.txt` prices. A kind says
# what the wait is for, not where the element lives: a menu item and a saved
# view's card are both `item`, because both are rows in a list that may be
# animated or re-ordered.
#
# Ids are written the way the flow writes them, minus the quotes. A templated id
# (`task_item_${RUN_ID}_buy_milk`) is one id and is listed under the template:
# the runner substitutes the value, the shape of the element does not change.
#
