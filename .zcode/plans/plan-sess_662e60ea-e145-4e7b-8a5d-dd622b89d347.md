# Plan: WYSIWYG Editor for Notes (Improved v2)

## TL;DR

**Замена AppFlowy не требуется** — AppFlowy отсутствует в кодовой базе. Проект уже хранит plain markdown в `notes.body_markdown`, имеет `multiplatform-markdown-renderer` в зависимостях, но **не имеет редактора вообще** (только список заметок). План добавляет rich-text редактор и инкапсулирует имплементацию за интерфейсами для mock-free тестирования.

## Kotlin Best Practices применённые

| Техника | Где | Эффект |
|---|---|---|
| **DSL builder + `@DslMarker`** | `ToolbarStateBuilder` для editor toolbar | `toolbar { enable(Bold, Italic); toggle(H1) }` |
| **Inline reified + `KSerializer<T>`** | `MarkdownHtmlPort` round-trip | Убирает передачу типов в runtime |
| **Value classes** | `@JvmInline value class EditorAction` | Zero-overhead type-safety для toolbar actions |
| **Sealed class** | `EditorState` (Loading/Editing/Saving/Error) | Exhaustive `when` в UI |
| **`@Serializable` defaults** | `NoteDto.legacyBodyHtml: String? = null` | Старые backup'ы десериализуются без ошибок |
| **Computed property** | `NoteEntity.bodyHtml` через `MarkdownHtmlPort` | Убирает миграцию БД |
| **Fun interface** | `fun interface MarkdownHtmlPort` | SAM-convertible для тестов |
| **Single NotesStore interface** | `NotesStore` (list + editor) | Единый контракт, один test fake |
| **Mock-free testing** | `FakeNoteStore` (in-memory map) | Тестируем ЛОГИКУ не имплементацию |

## *args/**kwargs в Kotlin — НЕТ прямого аналога

Python `*args`/`**kwargs` → Kotlin заменяет через:

```kotlin
// *args → vararg + spread
fun format(vararg parts: String): String = parts.joinToString(" ")

// **kwargs → DSL builders с @DslMarker  
toolbar {
    enable(Bold, Italic)
    toggle(H1)
    disable(Code)  // named args внутри builder
}
```

## Reflection — НЕ используем в production

- Все conversions — `inline reified` + `KSerializer`
- Никакого `KClass.memberProperties` в runtime

## Кодогенерация — НЕ добавляем

- Room: уже генерирует DAO через KSP
- Koin annotations: НЕ используем (manual DI как везде)
- Compose: компилируется Compose Compiler

   ```kotlin
   class NotesViewModel(
       private val store: NotesStore,
       private val htmlPort: MarkdownHtmlPort,
       coroutineScope: CoroutineScope = CoroutineScope(SupervisorJob() + Dispatchers.Default)
   ) : ViewModel() {
       // list state — existing
       private val _notes = MutableStateFlow<List<Note>>(emptyList())
       val notes: StateFlow<List<Note>> = _notes.asStateFlow()
       
       // editor state — new (sealed)
       private val _editorState = MutableStateFlow<EditorState>(EditorState.Empty)
       val editorState: StateFlow<EditorState> = _editorState.asStateFlow()
       
       private var autosaveJob: Job? = null
       
       fun openEditor(noteId: String) { /* loads Note + converts bodyMarkdown → bodyHtml via htmlPort */ }
       fun editBody(id: String, html: String) {
           _editorState.update { it.copy(html = html, isDirty = true) }
           autosaveJob?.cancel()
           autosaveJob = coroutineScope.launch {
               delay(500)  // debounce
               val md = htmlPort.toMarkdown(html)
               store.update(id, _editorState.value.title, md)
               _editorState.update { it.copy(isDirty = false) }
           }
       }
       fun editTitle(id: String, title: String) { /* same debounce */ }
       fun createNote(title: String = ""): String = store.create(UserId("anonymous"), title, "")
   }
   
   sealed interface EditorState {
       data object Empty : EditorState
       data class Editing(val id: String, val title: String, val html: String, val isDirty: Boolean) : EditorState
       data class Saving(val id: String) : EditorState
       data class Error(val id: String, val message: String) : EditorState
   }
   ```

   ```kotlin
   @DslMarker annotation class ToolbarDsl
   
   data class ToolbarState(val enabled: Set<EditorAction> = emptySet()) {
       @ToolbarDsl class Builder {
           val enabled = mutableSetOf<EditorAction>()
           fun enable(vararg actions: EditorAction) { enabled += actions }
           fun disable(vararg actions: EditorAction) { enabled -= actions }
           fun toggle(action: EditorAction) { if (action in enabled) enabled -= action else enabled += action }
           fun build(): ToolbarState = ToolbarState(enabled.toSet())
       }
   }
   
   fun toolbarState(block: ToolbarState.Builder.() -> Unit): ToolbarState =
       ToolbarState.Builder().apply(block).build()
   ```

9. **`shared/src/commonMain/kotlin/com/singularity/todo/feature/notes/NoteEditorScreen.kt`** (NEW):
   ```kotlin
   @Composable
   fun NoteEditorScreen(
       noteId: String?,
       onBack: () -> Unit,
       viewModel: NotesViewModel = koinViewModel()
   ) {
       val state by viewModel.editorState.collectAsStateWithLifecycle()
       val scope = rememberCoroutineScope()
       
       LaunchedEffect(noteId) {
           if (noteId != null) viewModel.openEditor(noteId)
           else viewModel.createNote()
       }
       
       NoteEditorScreenContent(
           uiState = state,
           onTitleChange = { viewModel.editTitle(state.id, it) },
           onBodyChange = { viewModel.editBody(state.id, it) },
           onBack = onBack
       )
   }
   
   @Composable
   fun NoteEditorScreenContent(
       uiState: EditorState,
       onTitleChange: (String) -> Unit,
       onBodyChange: (String) -> Unit,
       onBack: () -> Unit
   ) {
       // Pure presentation — testable without VM/Store
       Scaffold(
           topBar = { TopAppBar(title = { Text("Note") }, navigationIcon = { IconButton(onBack) { Icon(Icons.AutoMirrored.Filled.ArrowBack, null) } }) }
       ) { padding ->
           Column {
               when (uiState) {
                   EditorState.Empty -> CircularProgressIndicator()
                   is EditorState.Editing -> EditorBody(uiState, onTitleChange, onBodyChange)
                   is EditorState.Saving -> CircularProgressIndicator()
                   is EditorState.Error -> Text("Error: ${uiState.message}")
               }
           }
       }
   }
   
   @Composable
   private fun EditorBody(state: EditorState.Editing, onTitleChange: (String) -> Unit, onBodyChange: (String) -> Unit) {
       val richState = remember { RichTextState() }
       LaunchedEffect(state.html) {
           if (richState.toHtml() != state.html) richState.setHtml(state.html)
       }
       Column {
           OutlinedTextField(value = state.title, onValueChange = onTitleChange, ...)
           RichTextEditor(state = richState, onValueChange = { onBodyChange(richState.toHtml()) })
           Toolbar(actions = EditorAction.all) { /* toggle actions on richState */ }
       }
   }
   ```

## Тестируем ЛОГИКУ, не ИМПЛЕМЕНТАЦИЮ

| Что | Как тестируем | Без моков |
|---|---|---|
| ViewModel state transitions | `runTest + TestScope + Turbine` | `FakeNoteStore` (in-memory) |
| Markdown round-trip | property tests | `MarkdownHtmlPort` interface — любая impl |
| Editor flow integration | end-to-end через VM | `FakeNoteStore` + `FakeMarkdownHtmlPort` |
| Toolbar DSL | unit tests на `toolbarState { ... }` | Чистый DSL, no dependencies |

**Имплементация полностью инкапсулирована** за интерфейсами (`NotesStore`, `MarkdownHtmlPort`) — тесты не знают про Room, SQL, или richeditor.

## Risks

| Risk | Mitigation |
|---|---|
| `body_html` legacy column → minor storage waste | `@Deprecated`, не читаем; чистим в будущей migration |
| Compose Rich Editor crash на Compose 1.12 (open issue) | Pinned к 1.11.1 (matches project) |
| HTML→Markdown lossy tables/images | Document в `MarkdownHtmlPortTest.kt`, round-trip для 80% случаев |
| Debounce autosave race при быстром typing | `Job.cancelAndJoin()` + `delay(500)` |
| RichTextEditor Material3 theming на Desktop | Use `RichTextEditorDefaults` + manual testing |

## Out of Scope
- Tasks `TaskEntity.description` (plain text — без rich-text)
- Slash commands / mentions / hashtags (experimental, defer)
- Collaborative editing / Yjs (rejected)
- Tables / image embedding (lossy в md round-trip)
