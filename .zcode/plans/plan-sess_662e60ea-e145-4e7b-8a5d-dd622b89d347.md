# Plan: Secure Storage · Settings · Reminders · AI (KMP-native, test-first, no boilerplate)

## TL;DR

Four feature areas ported from the Flutter Singularity TODO app, **refactored for KMP idioms** — no 1:1 Dart→Kotlin translation. Encapsulate implementation behind `expect/actual` ports. Test **logic**, not implementation. Use Koog (KMP-native agent framework), Kotlin string templates (no Handlebars), reflection over `@Serializable` for JSON schemas, and Koin's `@ComponentScan` to auto-register tools.

## Boilerplate-reduction strategy applied throughout

| Concern | Pattern used | Why |
|---|---|---|
| `**kwargs` from Flutter | Kotlin **named args** + **DSL builders** with `@DslMarker` | Compile-time safe, no `Class<*>` or `KClass` needed |
| 16 GenAI tool schemas (Flutter: 528 LOC of `defineTool` calls) | `inline reified` + `KSerializer<T>.descriptor` walk (one ~30 LOC helper) | Reflect over `@Serializable` data classes — schema auto-stays-in-sync with code |
| 10+ DataStore preference keys | `multiplatform-settings 1.3.0` + `inline fun <reified T> keyOf<T>(name)` factory | Single line per key, full type safety |
| Settings UI form state | `data class FormState(...)` + `var field by remember { mutableStateOf(...) }` per field | Compose-native, no generator |
| State machines | `sealed interface` + `data object` + `data class.copy()` + `stateIn(scope, SharingStarted.WhileSubscribed(), initial)` | stdlib only, exhaustive `when`, zero deps |
| Tool/ViewModel registration | Koin `@ComponentScan` (compiler plugin, replaces deprecated KSP) | No manual `module { single { ... } }` boilerplate |
| Mock-free testing | `kotlin.test` + `runTest` + `UnconfinedTestDispatcher` + Turbine + in-memory fakes (interfaces, not mocks) | Test state transitions, not implementation |
| Error mapping | `sealed class AppError` + `Result<T>` | Type-safe exhaustive handling; one mapping helper |
| Type-safe IDs | `@JvmInline value class` (e.g. `NoteId`, `ReminderId`) | Zero cost, no Lombok-style generated equals/hashCode |

## What is NOT ported verbatim

- **Genkit `.prompt` Handlebars files (11 files)** → Kotlin `const val` strings with string templates. Migration path: keep the same prompt text but render with `"$currentTitle"`. No template engine needed.
- **Genkit `defineTool<Input, Output>` × 16** → Koog `SimpleTool<T>` × 16 with reflection-extracted schemas. Net reduction: ~528 LOC → ~250 LOC.
- **`FlutterSecureStoragePort` plugin wrapper** → `expect/actual SecureStoragePort` with `secret-tool` shell-out (JVM) and `EncryptedSharedPreferences` (Android). Same key names (`ai_key_openai`, `access_token`).
- **Riverpod providers** → Koin `@ComponentScan`. No per-tool registration line.

## Implementation phases

### Phase 1 — SecureStoragePort (4 files, ~150 LOC)

`expect/actual` pattern with platform-specific fallback chains.

1. **`shared/src/commonMain/kotlin/com/singularity/todo/core/security/SecureStoragePort.kt`** (NEW, ~15 LOC)
   ```kotlin
   interface SecureStoragePort {
       suspend fun read(key: String): String?
       suspend fun write(key: String, value: String)
       suspend fun delete(key: String)
       fun isHardwareBacked(): Boolean
   }
   ```
   No `expect` — pure interface, both targets are JVM so a single `JvmSecureStorage` impl dispatches internally.

2. **`shared/src/jvmMain/kotlin/com/singularity/todo/core/security/JvmSecureStorage.kt`** (NEW, ~120 LOC)
   - On Linux: shell out to `secret-tool` (libsecret CLI) — `Runtime.exec(["secret-tool", "store", "--label=$key", "key=$key"])` via `Dispatchers.IO`
   - On other JVM (macOS, Windows): same `secret-tool` if available, else fallback
   - Fallback: AES-GCM encrypted file at `~/.config/singularity/secure.bin` with Argon2-derived key from `System.getProperty("user.name")`
   - Auto-detect platform via `System.getProperty("os.name")`

3. **`shared/src/androidMain/kotlin/com/singularity/todo/core/security/AndroidSecureStorage.kt`** (NEW, ~50 LOC)
   - Wraps `androidx.security:security-crypto` `EncryptedSharedPreferences`
   - `add dependencies { "androidx.security:security-crypto:1.1.0-alpha06" }` to `gradle/libs.versions.toml`

4. **`shared/src/commonMain/kotlin/com/singularity/todo/core/security/FakeSecureStorage.kt`** (NEW, ~30 LOC)
   - In-memory `MutableMap<String, String>`; used in tests for both ports

### Phase 4 — AI Features with JetBrains Koog (12 files, ~600 LOC net reduction from Flutter)

The Flutter app has 528 LOC of `defineTool<Input, Output>(...)` × 16. Koog's `SimpleTool<T>` + a reflection-based JSON-schema helper reduces this to ~250 LOC.

1. **`gradle/libs.versions.toml`** — add:
   ```toml
   koog = "1.2.0"
   koog-agents = { module = "ai.koog:koog-agents", version.ref = "koog" }
   koog-openai = { module = "ai.koog:koog-openai", version.ref = "koog" }
   ```

2. **`shared/src/commonMain/kotlin/com/singularity/todo/feature/ai/schema/JsonSchemaReflection.kt`** (NEW, ~50 LOC)
   ```kotlin
   inline fun <reified T> jsonSchema(name: String, description: String): ToolSpec {
       val serializer = serializer<T>()
       val d = serializer.descriptor
       val props = buildMap {
           for (i in 0 until d.elementsCount) {
               put(d.getElementName(i), jsonTypeFor(d.getElementDescriptor(i)))
           }
       }
       val required = (0 until d.elementsCount).filter { !d.isElementOptional(it) }.map { d.getElementName(it) }
       return ToolSpec(name, description, JsonObject(mapOf(
           "type" to JsonPrimitive("object"),
           "properties" to JsonObject(props),
           "required" to JsonArray(required.map { JsonPrimitive(it) })
       )))
   }
   ```
   Reused by every tool below — single source of truth, schema stays in sync with `@Serializable` classes.

3. **`shared/src/commonMain/kotlin/com/singularity/todo/feature/ai/prompts/Prompts.kt`** (NEW, ~80 LOC)
   - All 11 Flutter `.prompt` files collapsed into one Kotlin object with `const val` strings
   - Example:
     ```kotlin
     object Prompts {
         const val refineSystem = "You are a productivity assistant. Rewrite the user's task title to be clearer, more actionable, and specific. Return only the rewritten title, no quotes."
         const val smartRewriteSystem = "..."
         // ...
         fun refineUser(currentTitle: String, description: String?): String =
             "Title: $currentTitle\nDescription: ${description ?: "(none)"}"
     }
     ```

4. **`shared/src/commonMain/kotlin/com/singularity/todo/feature/ai/tools/`** (NEW package, ~250 LOC):
   One `SimpleTool<T>` per Genkit tool. Each file:
     ```kotlin

     @Serializable data class RefineTaskOutput(val newTitle: String)

     class RefineTaskTool(private val settingsRepo: SettingsRepository) : SimpleTool<RefineTaskInput>() {

         override val name = "refine_task"
         override val description = "Rewrite the task title to be clearer and more actionable"
         override suspend fun execute(args: RefineTaskInput): RefineTaskOutput = ...
     }
     ```
   Files: `RefineTaskTool.kt`, `SmartRewriteTool.kt`, `GenerateDescriptionTool.kt`, `DecomposeTaskTool.kt`, `GenerateChecklistTool.kt`, `PickTimeTool.kt`, `ClusterTasksTool.kt`, `ClusterNotesTool.kt`, `WeeklyPlanTool.kt`, `ProjectReviewTool.kt`, plus 6 context-lookup tools (`GetTaskTool.kt`, `ListTasksTool.kt`, `GetNoteTool.kt`, `GetProjectTool.kt`, `GetChecklistTool.kt`, `ListLinkedTasksTool.kt`).

5. **`shared/src/commonMain/kotlin/com/singularity/todo/feature/ai/KoogAgentService.kt`** (NEW, ~80 LOC, replaces `OpenAiClient.kt`)
   ```kotlin
   class KoogAgentService(
       private val secureStorage: SecureStoragePort,
       private val settings: SettingsRepository
   ) {
       private val toolRegistry by lazy { ToolRegistry { tools(Koin.getAll<Tool>()) } }  // auto-registered
       private val agent by lazy {
           AIAgent(
               promptExecutor = simpleOpenAIExecutor(
                   apiKey = secureStorage.read("ai_key_openai").orEmpty(),
                   baseUrl = settings.aiBaseUrlBlocking()
               ),
               systemPrompt = Prompts.chatSystem,
               toolRegistry = toolRegistry
           )
       }
       fun streamChat(message: String): Flow<AgentEvent> = agent.runFlow(message)
   }
   ```
