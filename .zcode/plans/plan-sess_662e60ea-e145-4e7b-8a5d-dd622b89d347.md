# План v2: Attachments (Phase 10) — уменьшенный boilerplate

## Контекст

KMP не имеет attachment support. Flutter оригинал имеет систему с Supabase Storage + известные баги. Цель Phase 10: реализовать attachments в KMP — file picker, URL attachments, локальная персистенция, thumbnails, Coil 3. Supabase Storage — STUB (как в Phase 9).

## Kotlin-техники для boilerplate reduction

| Техника | Где |
|---|---|
| **Inline value classes** | `AttachmentId("att_<uuid>")` |
| **Sealed + exhaustive when** | `AttachmentType` |
| **Default + named args** | Конструкторы, VM вызовы |
| **DSL builders** | Тесты: `attachment { mimeType = "image/png" }` |
| **Computed properties** | `Attachment.isImage`, `Attachment.hasLocal` |
| **@JvmInline + sealed** | Type-safe IDs |
| **TypeConverters** | Typed enums в Room (вместо `String`) |

### *args/**kwargs — нет аналога
Используем **vararg + spread** + **default + named**.

## Pure logic

**`AttachmentDomain.kt`** (~30 LOC, pure):
```kotlin
object AttachmentDomain {
    private val URL_REGEX = Regex("^https?://[^\\s/$.?#].[^\\s]*$")
    fun validateUrl(url: String) { require(URL_REGEX.matches(url)) { ... } }
    fun generateAttachmentId(): AttachmentId = AttachmentId("att_" + UUID.randomUUID())
    fun buildLocalPath(dir: String, taskId: String, id: String, ext: String) = "$dir/$taskId/$id.$ext"
    fun extractExtension(filename: String) = filename.substringAfterLast('.', "").lowercase()
}
```

**`MimeTypes.kt`** (~40 LOC, pure):
```kotlin
object MimeTypes {
    private val TABLE = mapOf("png" to "image/png", "pdf" to "application/pdf", /* ... */, "" to "application/octet-stream")
    fun fromExtension(ext: String) = TABLE[ext.lowercase()] ?: "application/octet-stream"
}
```

**`FileChecksum.kt`** (~15 LOC, pure):
```kotlin
object FileChecksum {
    fun sha256(data: ByteArray): String =
        MessageDigest.getInstance("SHA-256").digest(data).joinToString("") { "%02x".format(it) }
}
```

**`Attachment.kt`** (computed properties):
```kotlin
data class Attachment(..., val type: AttachmentType, val mimeType: String?, ...) {
    val isImage get() = type == AttachmentType.Image || mimeType?.startsWith("image/") == true
    val isUrl get() = type == AttachmentType.Url
    val isFile get() = type == AttachmentType.File
    val hasLocal get() = localPath != null
    val hasRemote get() = remoteUrl != null
}
```

## Implementation (encapsulated)

**`FileSystem.kt`** (interface + impls):
```kotlin
interface FileSystem {
    suspend fun readBytes(path: String): ByteArray
    suspend fun writeBytes(path: String, data: ByteArray)
    suspend fun delete(path: String): Boolean
    suspend fun exists(path: String): Boolean
    suspend fun ensureDir(dir: String)
}
class JvmFileSystem : FileSystem { /* java.io.File impl */ }
class AndroidFileSystem(context: Context) : FileSystem { /* context.filesDir */ }
class MapFileSystem : FileSystem { /* in-memory Map<String, ByteArray> for tests */ }
```

**`AttachmentStorage.kt`** (orchestration):
```kotlin
class AttachmentStorage(private val fs: FileSystem, private val dir: String) {
    suspend fun saveFile(taskId: String, id: String, sourcePath: String, ext: String) = runCatchingResult {
        val target = AttachmentDomain.buildLocalPath(dir, taskId, id, ext)
        val data = fs.readBytes(sourcePath)
        fs.ensureDir("$dir/$taskId"); fs.writeBytes(target, data); target
    }
    suspend fun computeChecksum(localPath: String) = runCatchingResult {
        FileChecksum.sha256(fs.readBytes(localPath))
    }
}
```

## Room schema — bump to v3

```kotlin

data class AttachmentEntity(

    @ColumnInfo("user_id") val userId: String,

    @ColumnInfo("remote_url") val remoteUrl: String? = null,
    @ColumnInfo("file_size_bytes") val fileSizeBytes: Long = 0L,
    @ColumnInfo("mime_type") val mimeType: String? = null,
```
