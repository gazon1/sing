## 1. Kotlin best practices применённые

| Техника | Где | Эффект |
|---|---|---|
| **Inline reified** + `KSerializer<T>` | `jsonEncode/jsonDecode` helpers | Убирает передачу типов |
| **DSL builder + `@DslMarker`** | `ExportOptions`, `ImportOptions`, тестовые data | `backupOptions { userId = ... }` |
| **Sealed class errors** | `BackupError` | Exhaustive `when` в UI |
| **Map-based migration chain** | `BackupMigrations.migrate` | Расширение без изменения сигнатуры |
| **Value classes** | Уже: `AttachmentId`, `BackupId` | Zero-overhead type-safety |
| **`@Serializable` default + named args** | DTO конструкторы | Меньше positional args |
| **`copy()` + data classes** | Где возможно | Замена boilerplate setters |
| **Generic через `inline reified`** | Codec helpers | Без reflection в runtime |
| **Companion object serializer()** | Все @Serializable DTOs | Получаем сериализатор без `T::class.java` |

## 2. *args/**kwargs аналоги — НЕ используем как в Python

Kotlin не имеет прямого `**kwargs`. Используем:
- **DSL builder** для опций: `backupOptions { includeAttachments = true }`
- **Default + named args** для конструкторов: `AttachmentDto(title = "x", mimeType = "image/png")`
- **Spread + vararg** для коллекций: `tasks(*taskList.toTypedArray())`

## 3. Reflection — НЕ используем
- Все conversions — `inline reified` + `KSerializer`
- Никакого `KClass.memberProperties` в production коде

## 4. Кодогенерация — НЕ добавляем
- Room уже генерирует DAO через KSP
- Koin annotations НЕ используются (manual DI как в Phase 9/10)
- Новые annotation processors не нужны

### BackupDomain.kt (~50 LOC pure)
```kotlin
object BackupDomain {
    fun sha256Hex(bytes: ByteArray): String = FileChecksum.sha256(bytes)
    fun extractUserIdHash(userId: UserId): String = sha256Hex(userId.value.encodeToByteArray())

    fun buildManifest(
        appVersion: String, nowEpochMillis: Long, userId: UserId,
        payloadBytes: ByteArray, counts: EntityCounts
    ): BackupManifest = BackupManifest(
        formatVersion = BackupFormat.FORMAT_VERSION,
        appName = BackupFormat.MAGIC_HEADER,
        appVersion = appVersion,
        createdAtEpochMillis = nowEpochMillis,
        userIdHash = extractUserIdHash(userId),
        schemaVersion = BackupFormat.SCHEMA_VERSION,
        entityCounts = counts,
        payloadChecksum = sha256Hex(payloadBytes)
    )

    fun validateManifest(manifest: BackupManifest, payloadBytes: ByteArray): Result<Unit> = runCatching {
        if (manifest.formatVersion > BackupFormat.FORMAT_VERSION)
            throw BackupError.UnsupportedFormatVersion(manifest.formatVersion)
        if (manifest.schemaVersion > BackupFormat.SCHEMA_VERSION)
            throw BackupError.UnsupportedSchemaVersion(manifest.schemaVersion)
        if (manifest.payloadChecksum != sha256Hex(payloadBytes))
            throw BackupError.ChecksumMismatch(manifest.payloadChecksum, sha256Hex(payloadBytes))
    }
}
```

### BackupMigrations.kt (~20 LOC pure)
```kotlin
object BackupMigrations {
    val CURRENT = BackupFormat.SCHEMA_VERSION
    // Add migrations as: migrations[1] = { obj -> migrateV1ToV2(obj) }
    private val migrations: Map<Int, (JsonObject) -> JsonObject> = emptyMap()

    fun migrate(payload: JsonObject, from: Int, to: Int = CURRENT): JsonObject {
        require(from <= to) { "from ($from) > to ($to)" }
        return (from until to).fold(payload) { acc, v ->
            migrations[v]?.invoke(acc) ?: acc
        }
    }
}
```

### BackupError.kt

sealed class BackupError(message: String) : Exception(message) {

    class UnsupportedSchemaVersion(val version: Int) : BackupError("schemaVersion $version > current")

    class MalformedManifest(val reason: String) : BackupError(reason)
    class FileNotFound(val path: String) : BackupError("File not found: $path")

## 8. BackupOptions.kt — DSL builder (~50 LOC)
```kotlin
@DslMarker annotation class BackupDsl

@BackupDsl
class ExportOptionsBuilder {
    lateinit var userId: UserId
    lateinit var destPath: String
    var includeAttachments: Boolean = true
    var appVersion: String = "0.0.11-phase11"
    fun build() = ExportOptions(userId, destPath, includeAttachments, appVersion)
}

@BackupDsl
class ImportOptionsBuilder {
    lateinit var sourcePath: String
    lateinit var targetUserId: UserId
    var overwriteExisting: Boolean = true
    fun build() = ImportOptions(sourcePath, targetUserId, overwriteExisting)
}

fun exportOptions(block: ExportOptionsBuilder.() -> Unit): ExportOptions =
    ExportOptionsBuilder().apply(block).build()

fun importOptions(block: ImportOptionsBuilder.() -> Unit): ImportOptions =
    ImportOptionsBuilder().apply(block).build()
```

## 15. Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Kompress experimental API | Single-file scope, BackupCodec interface для swap |
| Schema migration mis-applied | Pure + tested; CURRENT=1 = identity today |
| User identity drift | Use AuthRepository.session.effectiveUserId (NOT Settings) |
| Backup from newer app | validateManifest rejects schemaVersion > CURRENT |
| Large attachments | Codec streams entries, no full-load in memory |
| Missing attachment files | Soft-fail + missingAttachmentIds in result |
| Atomicity (interrupted write) | Document; future tmp+rename |
| Supabase Storage deferred | Stub interface stable, UI works |

## 18. Boilerplate Reduction Summary

| Было | Стало | Эффект |
|---|---|---|
| 12 extension functions для DTO ↔ Entity | 6 converters + generic helpers | -40 LOC |
| Sealed Exception через when в Manifest validation | Sealed `BackupError` + exhaustive when | Compile-time safety |
| Manual migration chain через when | `Map<Int, JsonObject→JsonObject>` | Extension без изменений |
| BackupCodec interface + Kompress в разных файлах | Один файл, опт-ин только в impl | -1 file |
| Repository с 6 suspend функций | DSL options (2 builders) | Читаемость + named args |
| Plain data class для опций | `@DslMarker` + builders | Защита от scope leakage |
| Mock-based tests | MapFileSystem + real Room in-memory + DSL builders | Mock-free |
