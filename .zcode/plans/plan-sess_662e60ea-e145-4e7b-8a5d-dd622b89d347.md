# План v2: Supabase Auth + Sync (Phase 9)

## Контекст
KMP: Ktor+Koin+Room+DataStore подключены, но `HttpClient` ни создан, Room v1 без sync метаданных, DI stub. Flutter оригинал имеет полный Supabase auth + sync на Edge Functions (`sync_shadows`/`sync_log`/`applied_patches`). Цель: портировать auth + sync с совместимостью с сервером. Pure logic для тестов без моков, инкапсулированная реализация, минимум boilerplate.

## Kotlin-техники для сокращения boilerplate

| Техника | Где |
|---|---|
| **Default + named args** | Конструкторы, VM вызовы |
| **Sealed + exhaustive when** | Уже для Session/TaskFilter |
| **Inline value classes** | `Hlc`, `UserId`, `TaskId` |
| **DSL builders** | Тестовые data: `session { signedIn = true }` |
| **Reified type params** | Убирает `Class<T>` параметры |
| **Koin annotations** (`@Module @ComponentScan` + `@Single`) | Полная замена ручного `module { }` — KSP генерирует DI |
| **kotlinx.serialization** | Для всех wire DTO |
| **Observer через `SharedFlow`** | Вместо extension `SyncTrigger` в каждом репо |

### *args/**kwargs в Kotlin
**Прямого аналога нет.** Используются: **vararg + spread** (`*list`) для позиционных, **default + named** для kwarg-like. Named args + defaults покрывают 99% случаев.

### 9B.1 Sync domain — pure

**`core/sync/SyncProtocol.kt`** — все DTO + extensions в одном файле (1:1 с Flutter):
```kotlin
@Serializable data class BatchPushRequest(val protocolVersion: Int = 1, val deviceId: String, val patches: List<DeltaPatch>)
@Serializable data class BatchPushResponse(val results: List<PatchResult>)
@Serializable data class DeltaPatch(val patchId: String, val entityId: String, val entityType: DocType,
    val baseVersion: Long, val protocolVersion: Int = 1, val isDelete: Boolean = false,
    val shadowChecksum: String?, val ops: List<FieldChange>, val timestampMs: Long? = null)
@Serializable data class FieldChange(val field: String, val op: FieldOp, val value: JsonElement? = null)
enum class FieldOp { SET, UNSET, APPEND, REMOVE }

    val conflict: Boolean = false, val newVersion: Long? = null, val newState: JsonElement? = null,

@JvmInline value class Hlc(val encoded: String) : Comparable<Hlc> {
    val physical: Long get() = encoded.substringBefore(':').toLong()
    val counter: Int get() = encoded.split(':')[1].toInt()
    val node: String get() = encoded.substringAfterLast(':')
    override fun compareTo(other: Hlc): Int =
        compareValuesBy(this, other, Hlc::physical, Hlc::counter, Hlc::node)
    companion object {
        fun tick(last: Hlc?, node: String, now: Long): Hlc { /* ~10 LOC */ }
        fun tock(local: Hlc, remote: Hlc, node: String, now: Long): Hlc { /* ~10 LOC */ }
    }
}
```

**`core/sync/ConflictResolver.kt`** — pure object:
```kotlin
object ConflictResolver {
    fun merge(local: JsonObject, remote: JsonObject, localHlc: Hlc?, remoteHlc: Hlc?): JsonObject =
        buildJsonObject {
            (local.keys + remote.keys).forEach { field ->
                val l = local[field]; val r = remote[field]
                put(field, when {
                    r == null -> l ?: JsonNull
                    l == null -> r
                    remoteHlc != null && localHlc != null && remoteHlc > localHlc -> r
                    else -> l
                })
            }
        }
    fun checksum(state: JsonObject): String = sha256(state.toString().toByteArray()).toHex()
}
```

### 9B.2 Repository observer — заменяет SyncTrigger extensions

В `TaskRepository` (и др.):
```kotlin
interface TaskRepository {
    val changes: SharedFlow<Task>
    suspend fun create(task: Task): Result<Unit>
}
class TaskRepositoryImpl(...) : TaskRepository {
    private val _changes = MutableSharedFlow<Task>(extraBufferCapacity = 64)
    override val changes: SharedFlow<Task> = _changes.asSharedFlow()
    override suspend fun create(task: Task) = runCatchingResult {
        dao.upsert(task.toEntity()); _changes.emit(task)
    }
}
```

`SyncEngine` подписывается на `combine(taskRepo.changes, noteRepo.changes, ...)` — **никаких extension-функций в репозиториях**.
