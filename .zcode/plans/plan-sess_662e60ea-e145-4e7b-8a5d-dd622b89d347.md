# План переноса Singularity Todo на KMP/CMP (минимальный boilerplate)

## Контекст

**Flutter-проект** (`/home/max/singularity_clone/singularity_todo_app`): todo-list с заметками, проектами, тегами, AI. 86 пакетов, ~129K LOC, Drift, Riverpod 3, Supabase REST, Genkit.

**KMP-проект** (`/home/max/AndroidStudioProjects/singularity_cllone_kmp`): пустой шаблон — `:shared`, `:androidApp`, `:desktopApp`, Compose Multiplatform 1.11.1, Material 3 alpha, Kotlin 2.4.10, AGP 9.4.0, Gradle 9.6.0, JDK 21.

**MVP:** Tasks + Notes + Projects + Tags + Search + 1 AI flow.

**Стек:** Koin 4.x (annotations), Room 2.8.4, Voyager, OpenAI через aallam/openai-kotlin, MaterialKolor, Kermit, kotlinx-serialization + kotlinx-datetime. Только `.deb`.

---

## Главные техники сокращения boilerplate

| Техника | Что даёт |
|---|---|
| **Koin annotations (`@Module @ComponentScan` + `@Single`/`@Factory`/`@ViewModel`)** | Compile-time генерация DI модулей — никаких `module { single { ... } }` вручную |
| **Room data class = Entity (без маппера)** | Entity и domain-модель — один класс |
| **`StateFlow.stateIn(scope, WhileSubscribed(5000), initial)`** | Заменяет `MutableLiveData + Job + try/catch` |
| **Sealed interface + `data object`** | Exhaustive `when`, авто `toString` |
| **Voyager `Screen` data classes** | Type-safe навигация через конструктор |
| **`Result<T>` + `runCatchingResult`** | Без своего sealed `Failure` |
| **`@JvmInline value class`** | Zero-overhead обёртки `TaskId(val value: String)` |
| **`@Serializable` + sealed** | JSON без ручных маппингов, полиморфизм через discriminator |

**НЕ используем:** `kotlin-reflect`, ручные `Mappers`, `MutableLiveData`, `try/catch` для control flow, ручные `Job` cancellation.

### 2. Ядро (4 задачи)

**2.1 Модели** — `@Serializable @JvmInline value class TaskId(val value: String) { companion object { fun generate() = ... } }`. `data class Task(...)` с computed `isCompleted`/`isTrashed`. Enums `TaskPriority`, `TaskKind`. Sealed `TaskFilter` с `@SerialName` на каждом подтипе. Аналогично `Note`, `Project`, `Tag`.

**2.2 Room** — `@Serializable @Entity data class TaskEntity` (поля с `@ColumnInfo`, ID как String). `TaskTagCrossRef` для many-to-many. `@Dao interface TaskDao` с `Flow`+`suspend` методами (`watchActive`, `watchById`, `upsert`, `softDelete`, `restore`, `search`, `upsertTagCrossRef`, `removeTagRef`). `@Database` с `@ConstructedBy(AppDatabaseCtor::class)`. `expect class AppDatabaseCtor : RoomDatabaseConstructor<AppDatabase>`. Actual в androidMain (AndroidX SQLite driver) / jvmMain (BundledSQLiteDriver).

**2.3 Koin через annotations:**
```kotlin
// core/di/AppModule.kt
@Module @ComponentScan("com.singularity.todo")
class AppModule

@Single
class TaskRepository(private val taskDao: TaskDao, ...) {
    fun watchTasks(userId: UserId, filter: TaskFilter): Flow<List<Task>>
    suspend fun create(task: Task): Result<Unit> = runCatching { taskDao.upsert(task.toEntity()) }
}

@Factory
class CreateTaskUseCase(private val repo: TaskRepository, private val clock: Clock) {
    suspend operator fun invoke(input: CreateTaskInput): Result<TaskId> = runCatchingResult {
        require(input.title.isNotBlank()) { throw AppError.Validation("Title cannot be blank") }
        val now = clock.now()
        val task = Task(id = TaskId.generate(), ..., createdAt = now, updatedAt = now, userId = input.userId)
        repo.create(task).getOrThrow(); task.id
    }
}

@ViewModel
class TasksViewModel(...) : ViewModel() {
    private val filter = MutableStateFlow<TaskFilter>(TaskFilter.Today)
    val state: StateFlow<TasksUiState> = filter
        .flatMapLatest { getTasks(currentUserId, it) }
        .map<List<Task>, TasksUiState> { TasksUiState.Content(filter.value, it) }
        .catch { emit(TasksUiState.Error(it.message ?: "Error")) }
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), TasksUiState.Loading)
    fun setFilter(f: TaskFilter) { filter.value = f }
}
```

**2.4 Core utils** — sealed `AppError` (Validation/NotFound/Persistence/Network/Unknown), `inline fun <T> runCatchingResult(block: () -> T): Result<T>`, `expect object Clock { fun now(): Instant }`, `expect interface PlatformContext { val databasePath; val preferencesPath; val cachePath }`.

### 3. Domain фич (5 фич параллельно)

Все фичи по одному шаблону:
- `sealed interface *UiState { data object Loading; data class Empty(...); data class Content(...); data class Error(message) }`
- `@Single class *Repository(...)`
- `@Factory class *UseCase(...) { operator fun invoke(...) }`
- `@ViewModel class *ViewModel(...) : ViewModel()` с state через `stateIn`
- `class *Screen : Screen { @Composable override fun Content() { val vm = koinViewModel<...>(); val state by vm.state.collectAsStateWithLifecycle() } }`

**Notes:** Markdown preview через `multiplatform-markdown-renderer`, editor — `BasicTextField` с Edit/Preview tabs.

**Search:** один `SearchUseCase(query)` через `combine(tasks, notes, projects, tags)`.

## Минимальный API для новой фичи (scaffold за 5 минут)

```kotlin
@Entity data class ReminderEntity(@PrimaryKey val id: String, val taskId: String, val fireAt: Instant)
@Dao interface ReminderDao { @Query("...") fun watchForTask(id: String): Flow<List<ReminderEntity>>; @Upsert suspend fun upsert(r: ReminderEntity) }
@Single class ReminderRepository(private val dao: ReminderDao, private val clock: Clock)
@Factory class GetRemindersUseCase(private val repo: ReminderRepository) { operator fun invoke(taskId: TaskId) = repo.watch(taskId) }
@ViewModel class RemindersViewModel(getReminders: GetRemindersUseCase) : ViewModel()
class RemindersScreen(private val taskId: TaskId) : Screen { @Composable override fun Content() { val vm = koinViewModel<...>() } }
```

`@ComponentScan` автоматически регистрирует всё в Koin. Каждая фича ~150-300 LOC, изолирована.
